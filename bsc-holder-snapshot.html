What this checks

Paste any BEP-20 token contract and any wallet. This tool reads the token straight from BNB Smart Chain and shows:

  • Balance — the wallet's balance of that token (raw and human-readable, using the token's own decimals).
  • Total supply — the token's total supply from the contract.
  • Share of supply — the wallet's balance as a percentage of total supply.
  • Block and fetch time — the latest BSC block the read was taken at, and the UTC time it was fetched, so a later disagreement is about staleness, not arithmetic.

What it cannot check: holder rank. This tool shows one wallet's share of supply; it does not rank that wallet against all holders, and it does not check whether the token is worth anything — a large share of a token nobody wants is still worth nothing. A token contract that has no code at the address you paste is not a token at all, and this tool will say so.
